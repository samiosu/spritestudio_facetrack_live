# ソース公開とバイナリ配布

初期版の自作アプリ本体・デモはMITです。自作補助スクリプトとそのテストの
GPL-3.0-or-later指定は[依存一覧](DEPENDENCIES.md)に記載しています。
それらを配布する場合は`COPYING.GPL-3`も含めます。必要な依存表示は
`THIRD_PARTY_NOTICES.md`、`licenses/`、`docs/DEPENDENCIES.md`にあります。
第三者コードを自作のMITへ変更することはありません。

ソース公開時は、ビルド手順・依存の固定値・SDK拡張の内容・ライセンスを含めます。
モデルはGitへ入れず、`tools/fetch_models.py`で固定SHA-256を検証して取得します。
モデルを含むスマホアプリを配布する場合も、そのモデルのライセンスを含めます。

バイナリの公開前には、実際の配布物を対象に次を確認します。

- 必要なライセンス・著作権・NOTICEを同梱していること。
- スマホSDKに含まれるネイティブライブラリの内部依存の表示が揃っていること。
- GPL／LGPLを同梱する場合、対応ソースと必要な差し替え条件を満たしていること。
- タグのソース、ビルドスクリプト、依存バージョンがバイナリに対応していること。
- 実機のカメラ・権限・LAN接続、OBS取り込みで動作すること。

PrivateリポジトリのGitHub Actionsでビルド検証を実行しています。
PCの開発ビルドとテストレポートはPrivateのCI artifactとして保存し、
一般公開のReleaseやモバイルアプリの配布は行っていません。
AndroidのAPK配布はライセンス・実機確認の後に行う方針です。
App Store配布にはApple側の署名・審査・配布条件の確認が必要です。
